# 🎮 Trabalho
Este repositório contém o meu Trabalho Final do curso React e Java Script do IFSC Canoinhas, entregue dia 30/01/2026.

# 📌 Sobre Projeto

O  desenvolvimento consiste em um controle de gastos financeiros, onde o usuário adiciona seus lucros e/ou despesas e visualiza eles na tela com todos os informativos, bem como o saldo final do mesmo.

Foi desenvolvido com HTML, CSS e Java Script. Não consegui utilizar React por problemas em minha máquina.

Futuramente, quando melhorar meu computador, implementarei o react a esse desenvolvimento.

# 🔧 Funcionalidades do Programa

O programa Permite:

*  Adição de uma descrição do gasto/lucro.
*  Adição de valores com campo input.
*  Seleção de lucro ou gasto com campo check list.
*  Adição de uma categoria ao gasto/lucro.
*  fucionalidade de dark/light.
*  Visualização do Lucro, gasto e somatório na tela.

Tudo isso com JS puro.
